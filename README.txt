SPEEDTEST INDONESIA — V3 (tanpa panel admin dan tanpa pelacakan IP/lokasi)

File:
- index.html: halaman website
- style.css: desain responsif
- app.js: pengujian download/upload/ping/jitter dan rekomendasi

Cara menjalankan:
1. Ekstrak ZIP di HP Android menggunakan aplikasi pengelola file.
2. Untuk mengedit, buka folder di editor kode seperti Acode.
3. Upload index.html, style.css, dan app.js ke hosting statis (misalnya Netlify).
4. Buka domain website dari browser HP.

Privasi:
- Panel admin dihapus.
- Tidak ada login admin.
- Tidak ada pengambilan IP publik, ISP, kota, GPS, atau lokasi.
- Tidak ada database dan hasil tes tidak dikirim/disimpan oleh website.
- Tes menggunakan endpoint publik Cloudflare Speed Test; hasil bergantung kondisi jaringan dan server.

Rekomendasi:
- Saran paket internet dihitung dari hasil tes aktual, jumlah perangkat, aktivitas, dan ukuran rumah.
- Saran router mempertimbangkan ukuran rumah; spesifikasi WiFi 6/mesh hanya panduan, bukan kewajiban.
- Daftar ISP mengarah ke situs resmi. Cek cakupan, harga, dan paket terbaru langsung ke ISP karena bisa berubah dan berbeda per alamat.

Catatan teknis:
- Pengujian memakai sekitar 5 MB download dan 2 MB upload, selain overhead.
- Jika tes gagal, coba jaringan lain, matikan VPN/ad blocker sementara, atau ulangi beberapa saat kemudian.

Video latar: background.mp4 dipasang autoplay, muted, loop, playsinline. Upload bersama index.html, style.css, dan app.js dalam folder yang sama. Browser HP dapat menunda autoplay untuk menghemat baterai/data.
